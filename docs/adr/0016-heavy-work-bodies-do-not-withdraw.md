# Heavy-Work bodies do not Withdraw: the first comparative applicability gate

> **Revised by ADR 0048** on the accepted detour: "the one remaining detour — a full Anchor off-post matching Upgrade once — empties it and converges, and is accepted" becomes **never**. There was no *once* — every release put the same body back at the same gate — so Upgrade is now applicable to a Work-heavy body only where it may already act on it, and a full Anchor off its Post keeps Harvest and walks back onto the Post instead. The comparative Withdraw gate this ADR decided, and the no-role axiom it narrowed, stand unchanged.

Live observation of W12S28 (RCL3, both sources holding container Posts) falsified ADR 0012's pinning assumption. The second Anchor, spawned for the far source's Post, never manned it: Harvest at that Post (rank 0, travel cost 76 for the heavy body) lost every rematch to Withdraw from its sibling Anchor's source container (rank 0, cost 17), locking the creep into a withdraw→upgrade orbit near the controller — a parasite recycling energy its sibling had already dug, while the unmanned source sat near-full and the income-based workforce target kept counting its 10 e/tick as income it wasn't earning. Travel-cost pinning (ADR 0006, restated by ADR 0012's #47 amendment) pins an Anchor that is *at* its Post; it does not deliver one that spawned nearer a stocked container, because Withdraw sits at the same feeding tier and the tie falls to distance every time. We decided **Withdraw is inapplicable to a body with more Work than Move parts** — the same arithmetic spawn planning already reads the anchor row by (`isAnchorBody`). This is part-based applicability extended from a presence test ("has Carry") to a comparative one, still computed from what the creep is made of, never from a name or a birth role: the no-role axiom stands. The guarantee is emergent, as the house style demands: an empty heavy-Work body's only feeding-tier candidate is Harvest, so an unmanned reachable Post wins it regardless of distance, and the Matcher's ordinary release-and-rematch walks the Anchor home. Two principles narrow: ADR 0006's "gates are body-blind" becomes "gates are body-*arithmetic*", and ADR 0012's "travel cost arbitrates dig-vs-collect" now holds only for bodies that are not Work-heavy — a worker's choice between digging and collecting is still priced, never ruled.

## Considered Options

- **Capability scoring in the Matcher (rank Harvest up, or Withdraw down, for heavy-Work bodies)** — rejected: ADR 0006 refused a second scoring axis as a mechanism without a proven need; the need is now proven, but the applicability vocabulary already expresses the decision in one comparison, and a per-body rank axis is strictly more machinery for the same behaviour.
- **Body-blind target layering (demote source-container Withdraw below Harvest, ADR 0010 style)** — rejected: it demotes workers too — an empty worker beside a stocked container would walk to a seat instead of topping up in one tile, reviving exactly the commute ADR 0012 built the logistics layer to kill.
- **Colony-level Post assignment (plan which creep mans which Post)** — rejected, again (ADR 0006): role binding under another name, persistent per-creep state, and a fight with the per-tick-rebuild architecture on every front.
- **Gate only source-container Withdraw, leaving the controller container open to Anchors** — rejected: it would let a Dual-Seat Anchor top up during its source's drained window, but that room shape doesn't exist in the colony yet, the saved ticks are a few per 300-tick regen cycle, and the price is a kind-discriminating gate needing a paragraph of explanation. Revisit if a Dual-Seat room shows the loss.
- **Re-base workforce income on *manned* Posts instead of existing ones** — rejected: with the gate in place the mismatch is a self-healing transient (an Anchor gap until the spawn fills it), and ADR 0012 already refuses to coordinate transitions; wiring an on-post detector into the hiring arithmetic is coupling without a standing need.

## Consequences

- `applicable`'s doc comment ("body-blind like every gate here") is no longer true verbatim and must be rewritten to name this ADR; the invariant that survives is that gates read part counts, never names or roles.
- The Withdraw glossary entry gains a body clause; dig-vs-collect by travel cost is now explicitly a worker-body sentence.
- An Anchor spawns empty, so in practice its first match is Harvest at the open Post; the one remaining detour — a full Anchor off-post matching Upgrade once — empties it and converges, and is accepted.
- A Dual-Seat Anchor idles through its source's drained window instead of drawing from an adjacent controller container: the accepted loss of the simple gate.
- Deployment heals the live colony without a death: a kept Withdraw assignment on an anchor body releases as inapplicable on the first tick and rematches to the unmanned Post's Harvest.
- The test surface (DecideTests): an anchor body beside a stocked container with a reachable unmanned Post matches Harvest; a worker body in the same geometry still chooses by travel cost.
